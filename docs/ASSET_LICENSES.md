# Release asset inventory

Clean public source edition by Andrew Manuilov.

Active 3D buildings, walls, characters, terrain, SVG artwork and audio are generated by the project source in src/render/, src/ui/ and src/audio/. The 20 retained building portraits in public/assets/ui/buildings/ are documented by the source project as renders of its procedural models. All 20 portraits were regenerated with the tracked tools/building-portrait.html and tools/render-building-portraits.playwright.js against the actual procedural source on 2026-10-12. Every regenerated PNG is byte-identical (SHA-256) to the corresponding original. Their PNGs contain image chunks without EXIF/text metadata. The owner confirmed the projects are personal. This is recorded as the owner’s representation; automated scanning and reproduction do not independently prove copyright or NDA clearance.

The unmodified Manrope Cyrillic and Latin WOFF2 subsets use SIL OFL 1.1. Their bytes were compared with the documented official downloads on 2026-10-12 and match:

- Latin SHA-256: e310b55a7fd9677f5e3555e6c6c4d064fa1f1d24393f0ddbe217cea12a8c432f

Excluded from this clean export:

- All unused Kenney/Quaternius prototype GLB, glTF and textures, plus the unused AssetLibrary.ts loader.
- Historical playtest screenshots, QA logs and local test URLs.
- Poly Haven surfaces, previously removed upstream, and any Stronghold / Firefly assets.

Historical Kenney and Quaternius text records in public/assets/licenses/ are retained only as context for excluded prototypes. The Quaternius notice names Ultimate Platformer Pack while source documentation named Ultimate Fantasy RTS; it does not establish permission for the excluded files. Reintroducing any model requires verification of the exact source and license.

Third-party code keeps its own license. See THIRD_PARTY_NOTICES.md and third_party/.

To reproduce: start npm run dev, open tools/building-portrait.html in Playwright CLI, then run tools/render-building-portraits.playwright.js from the project directory. Outputs are 640 by 512 transparent PNGs.
